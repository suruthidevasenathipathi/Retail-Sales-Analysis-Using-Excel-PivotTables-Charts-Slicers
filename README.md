 Project Objectives

Summarize total profit across product categories.

Compare sales performance by region and category.

Analyze sales and profit across different sales channels.

Count orders by payment method.

Identify the top five products based on sales.

Analyze monthly sales trends.

Compare salesperson performance using profit.

Create interactive visualizations using PivotCharts and Slicers.

📂 Dataset Description

The dataset contains 300 retail sales records and 17 columns.

Key fields include:

Column

Description

Order ID

Unique order identifier

Order Date

Date of the transaction

Region

Geographical sales region

City

City where the order was recorded

Category

Product category

Product

Name of the product

Quantity

Number of units sold

Unit Price (INR)

Price per unit

Discount %

Discount applied to the order

Sales (INR)

Sales amount after discount

Cost (INR)

Cost associated with the order

Profit (INR)

Profit generated from the order

Customer ID

Customer identifier

Salesperson

Person responsible for the sale

Payment Method

Method used for payment

Sales Channel

Online or in-store

Order Status

Current order status

🛠️ Tools and Features Used

Tool: Microsoft Excel / Excel Online

Features practiced:

PivotTables: Summarizing, grouping, and comparing sales data.

PivotCharts: Presenting summarized information visually.

Slicers: Filtering supported PivotTables and PivotCharts interactively.

Sorting and filtering: Identifying top-performing products and comparing results.

Date-based analysis: Examining monthly sales performance.

Value aggregation: Calculating sums, averages, and order counts.

📊 Analysis Performed

Profit by Category: Compared total profit across different product categories.

Regional Sales Analysis: Compared sales across regions and product categories.

Sales Channel Analysis: Examined performance across online and in-store channels.

Payment Method Analysis: Counted orders by payment method.

Top Five Products: Identified products generating the highest sales.

Monthly Sales Trend: Analyzed sales performance over the year.

Salesperson Performance: Compared profit generated by individual salespeople.
